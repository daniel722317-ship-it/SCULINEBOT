# 📱 螢幕錄影 Checklist

## 錄影前準備

- [ ] **手機資料清空**：bot 上一個測試帳號的紀錄全刪（用「設定 → 刪除全部」做 clean state，影片才會看起來像新使用者）
- [ ] **網路穩定**：HF Space 在閒置 sleep 後第一次回應會慢 30 秒，**錄影前先傳一句「你好」讓它醒**
- [ ] **手機亮度開最高**，省得後期調色
- [ ] **靜音 + 開啟勿擾**：避免錄到通知聲
- [ ] **iPhone**：控制中心 → 螢幕錄影
- [ ] **Android**：通知欄拉下 → 螢幕錄製

---

## 錄影順序（建議分 5 段錄，剪輯時拼起來）

### 段 1：初次設定 (12s 用量 → 錄 30s 多備一些)
1. 退出 LINE 重進來，確認看到舊版聊天記錄
2. **先用「設定 → 刪除全部」清空**
3. 加好友（或重新 follow）→ 跳出 Welcome Flex
4. 點「⚙️ 建立個人資料」
5. 答完 8 題（盡量快、間隔 < 1 秒）
6. 等 TDEE Flex 卡完整顯示後停留 2 秒
7. **停錄**

### 段 2：Rich Menu 巡禮 (12s)
1. 在主畫面點底部「點開選單」展開 Rich Menu
2. 不點任何格子，**靜止 3 秒**讓觀眾看全景
3. 後期剪輯時加方框標示

### 段 3：運動模組 (20s)
1. 收起 Rich Menu，傳「運動」
2. 點「🔥 增肌」→「📋 訓練菜單」
3. **左右滑** Carousel 看完 5 套訓練 + 自訂卡
4. 點背部鍛鍊的「📖 動作詳解」
5. 滑 2-3 個動作詳解卡片
6. 回主畫面，傳「減脂」→「🔥 燃脂菜單」
7. 滑看 5 套燃脂菜單
8. **停錄**

### 段 4：打卡 + 力量 (15s)
1. 點 ✅ 打卡 → 💧 飲水打卡 → 350 ml
2. 等鼓勵語回應顯示
3. 返回，再點 🌙 睡眠打卡 → 😴 睡得好
4. 等回應
5. 返回，💪 運動打卡 → 🔥 增肌打卡 → ✏️ 力量紀錄
6. 打「深蹲」→「80」→「5」→「4」
7. 等 1RM 顯示
8. 點「💪 看我的力量」
9. **停錄**

### 段 5：AI 教練 (20s) ⭐ 最重要的段，多錄幾次取最好
1. 點底部 🤖 AI 教練 cell
2. 跳出免責聲明 → **停 2 秒讓觀眾看清條款**
3. 點「✅ 我同意，開始」
4. **特寫橘色機器人頭貼**出現 + 歡迎訊息（**鏡頭可以縮放這部分）**
5. 點 QR「📝 問動作姿勢」
6. 等教練回問
7. 打「深蹲膝蓋會內夾」
8. **等 4-6 秒**讓教練回應完整顯示
9. 打「結束」→ 教練說再見
10. **停錄**

### 段 6：統計 + 設定 (15s)
1. 點底部 📈 統計
2. **慢慢往下滑**Flex 卡（讓觀眾看到飲水/睡眠/運動/力量/反思/目標）
3. 按「📅 上個月」
4. 再按「📅 過去 7 天」
5. 返回主畫面，點 ⚙️ 設定 → 出現 QR
6. 點「🔔 通知設定」→ 顯示開關 Flex
7. **停錄**

## 後期合成順序

1. **影片素材匯入** CapCut（電腦版或手機版都行）
2. 依照分鏡稿順序拖到時間軸
3. **加速** 段 1-3 大概到 1.3-1.5 倍（讓節奏緊湊）
4. **轉場**：每段中間放 0.5 秒白閃光或交叉淡入
5. **匯入配音** mp3 到下方軌
6. **對齊配音與畫面** — 重點：當配音說「Rich Menu」時，畫面正好是 Rich Menu 巡禮
7. **加字幕** — CapCut 可以直接匯入 SRT，或自動辨識
8. **加配樂**——音量降到 20-30%（不蓋過旁白）
9. **加 Logo 浮水印**（右上角小角色：你的學號 + 課程名）
10. **匯出** 1080p / 30 fps / mp4

## 配音工具建議

### 免費（推薦先試）

1. **ElevenLabs**（https://elevenlabs.io）
   - 免費額度：10,000 字/月
   - 步驟：註冊 → 選 zh 音色（Charlotte、Bella 都不錯）→ 貼逐字稿 → 下載 mp3
   - 品質：⭐⭐⭐⭐⭐ 自然度最高

2. **Google AI Studio**（https://aistudio.google.com）
   - 免費，你已經有 GEMINI_API_KEY
   - 用「Text-to-Speech」功能、選 `zh-TW-Wavenet-A`
   - 品質：⭐⭐⭐⭐

3. **微軟 Edge Read Aloud**
   - 把逐字稿貼到 Edge 瀏覽器讓它朗讀，用螢幕錄影錄下來
   - 品質：⭐⭐⭐ 老氣一點但完全免費

### 付費更穩

1. **Murf.ai**（$19/月，有 10 分鐘免費試用）
2. **WellSaid Labs**（$44/月）

## 常見錯誤與解法

| 問題 | 解法 |
|---|---|
| 配音對不到嘴/時序 | 用 CapCut 的「自動 beat」對齊，或手動調軌道時間 |
| 螢幕錄影太大檔 | 匯出前先用 HandBrake 壓到 50-100 MB |
| 字幕跑得太快看不到 | 字幕最少停留 1.5 秒，太短就把畫面延後 |
| 配樂蓋過旁白 | 配樂音量設 20%、加 -3dB 壓縮 |
| 老師看不清楚 | 重點功能加「放大鏡」效果（CapCut → 編輯 → 縮放關鍵幀） |

## 一鍵繳交檢查表

- [ ] 影片長度 117-123 秒之間（不要超過 2 分鐘）
- [ ] 開頭有學號 + 姓名 + 課程
- [ ] 結尾有 QR code 給老師掃
- [ ] 字幕中文無錯字
- [ ] 旁白聽得清楚、不含背景雜音
- [ ] 配樂音量 < 旁白
- [ ] 解析度 1080p 以上
- [ ] 檔案 < 200 MB（Mail/雲端容易傳）
- [ ] mp4 / H.264 編碼（最相容）
